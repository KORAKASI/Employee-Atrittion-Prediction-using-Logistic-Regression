# Employee-Atrittion-Prediction-using-Logistic-Regression

## Project Overview

Employee attrition is a critical challenge for organizations, as high turnover rates can lead to increased recruitment costs, reduced productivity, and loss of valuable talent. This project aims to predict whether an employee is likely to leave the organization using Machine Learning techniques.

The model is built using **Logistic Regression**, a supervised classification algorithm, to identify patterns and factors associated with employee attrition.

---

## Objective

The objective of this project is to develop a predictive model that helps organizations identify employees at risk of leaving the company, enabling proactive retention strategies and informed decision-making.

---

##  Model Used

### Logistic Regression

Logistic Regression is a supervised machine learning algorithm used for binary classification problems. It predicts the probability of an instance belonging to a particular class.

The logistic function is defined as:

```
P(Y=1) = 1 / (1 + e^-(β₀ + β₁X₁ + β₂X₂ + ... + βₙXₙ))
```

Where:

- **Y** = Target Variable (Attrition)
- **β₀** = Intercept
- **β₁ ... βₙ** = Feature Coefficients
- **X₁ ... Xₙ** = Input Features
